# ethics4all-participation
Open research and contribution tasks for Ethics4All. Transparent evidence, critical review and synthetic examples. Existing private implementation code remains separate.

## Aufgaben

Öffentliche Aufgaben stehen als [Issues](https://github.com/intiequals1/ethics4all-participation/issues) bereit. Alle Aufgaben des Labors sammeln das [Projektboard](https://github.com/users/intiequals1/projects/6) und die [Aufgabenübersicht](https://github.com/intiequals1/digitalpath-site/issues/1).

- [#1 Produktentscheidung: Einstiegsproblem und Grenze zwischen Beratung und Auditor klären](https://github.com/intiequals1/ethics4all-participation/issues/1)
- [#2 Validierungsplan: datensparsamen Bedarfstest für das gewählte Einstiegsangebot entwerfen](https://github.com/intiequals1/ethics4all-participation/issues/2)

Ergebnisse kommen als Markdown oder CSV in den Ordner [`docs/`](docs/).
